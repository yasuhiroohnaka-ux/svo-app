### 1-2. 重大度: 中

- **ナビゲーション欠落**: Word Detective と Quiz Maker にはポータルへ戻るリンクがない。他アプリも「トップ」「← ポータルへ」「Portal」「← もどる」と表記・位置がバラバラ。
- **ランキング**: 名前入力モーダルは順位に関係なく常に「新記録!」と表示。ランキング一覧はクリア直後しか開けない。Quiz Maker は `setIsNewRecord` が未使用のため新記録行のハイライトが出ない。
- **`alert()` で勝敗表示**(SVO / Quiz Maker の VS 終了時)。子ども向け UI として唐突で、演出の機会も失っている。
- **Quiz Maker の選択肢数**: `setChoiceCount` がどこからも呼ばれず、4 択固定(UI が消えている)。
- **Quiz Maker の state 更新関数内での副作用**: `toggleVsMode` が `setIsVsMode(prev => …)` の中で他の `setState` や `resetGame()` を呼んでいる(StrictMode で 2 回実行される)。
- **oto-man の「認証」**: `?p=sound` か **パラメータなし**なら通る実装で、実質的に誰でも通過する。秘密値もクライアントに平文。残すなら意図をコメント化、不要なら削除。
- **localStorage を `useState` 初期化で読む**(oto-man の `autoAdvance` / 正解済み単語): SSR とクライアントで初期値がずれるとハイドレーション不一致の原因になる。Story Quiz / So-ta と同じ `useSyncExternalStore` 方式に寄せる。
- **Portal の「AI」タグ**: Word Detective はルールベースで AI ではない。誤解を招く表記。
- **メタデータ**: サイト全体のタイトルが "Puzzle Grammar"(9 アプリあるハブの名前として不適切)。`<html lang="en">` だが本文の大半が日本語。`viewport` / `theme-color` / アプリアイコン未設定。

### 1-3. 重大度: 低(保守性・品質)

- **重複実装**: SVO と Quiz Maker はタイマー・ランキング・VS・音声認識をほぼ同じコードで別々に持つ(SVO は `useGameTimer` 等にフック化済み、Quiz Maker は 1,321 行のページ内に直書き)。進捗ストアも Story Quiz / So-ta / oto-man / ranking の 4 系統、読み上げも `utils/speak.ts` / `storyquiz/lib/speech.ts` / `sota/lib/speech.ts` / Phonics Maze 直呼びの 4 系統。
- **lint**: 20 errors / 9 warnings(`no-explicit-any` 9、`scripts/*.cjs` の `require` 10、`exhaustive-deps` 5 など)。`tsc` は通過。
- **文字化けコメント**: `app/svo/page.tsx:1074`(`蟾ｦ: 逕ｻ蜒・`)。`app/quiz-maker/page.tsx` 先頭に BOM。
- **テストなし**: 判定ロジック(文の正誤、音声認識の緩い一致、迷路の正解判定、ダミーピース選択)は純関数化できるのに単体テストがない。
- **README** が create-next-app の雛形のまま。Cloudflare デプロイ手順・アプリ一覧・データの置き場所が書かれていない。
- **アクセシビリティ**: カード画像の alt が `card` / `choice-0` など。`:focus-visible` や `prefers-reduced-motion` への対応がほぼない。ボタン色だけで正誤を伝えている箇所がある(赤/緑の枠線のみ)。
- **Story Quiz の typing / speech モード**: 型と分岐はあるが「次のバージョンで追加予定」表示のまま。

## 2. ページデザイン改善計画

### 現状の見た目(スクショ確認)
- ポータルだけ **濃紺のピクセルアート調**、各アプリは **クリーム地 + 太枠 + オフセット影** の明るい系統。入口と中身でブランドが断絶している。
- ポータルはスマホで 9 枚のカードが縦一列。対象年齢・遊び方・進み具合の手がかりがなく、どれから遊べばいいか分からない。アイコンも絵文字と文字(`MZ`)が混在。
- 各アプリの上部は「戻る・言語・モード・速度・メニュー」がボタンの羅列になり、スマホでは **ゲーム画面が 1 画面目に入らない**(Word Detective は設定と統計だけで画面の大半を使う、SVO も 4 段のボタン列)。
- 読み上げ速度コントロールが各アプリで置き場所がバラバラ(Puzzle Grammar ではレベルボタンの間に挟まっている)。

### 方針
1. **デザイントークンの共通化**: `app/globals.css` に色・角丸・影・余白・フォントサイズの CSS 変数を定義し、各 `*.module.css` の直書き値を置き換える。アプリごとの差はアクセント色 1 色(ポータルカードの `--card-accent` をそのまま流用)だけにする。
2. **ポータルを明るい系統に揃える**(ピクセルフォントはロゴ・見出しのアクセントとして残す)。
3. **共通アプリシェル** `app/components/AppShell.tsx`: 左に「← ホーム」、中央にアプリ名、右に ⚙️(設定シート)。言語・速度・自動読み上げ・レベルなどの設定は **ボトムシート/モーダルにまとめ**、プレイ画面にはゲームに必要な操作だけを置く。
4. **ポータルの再構成**
   - 「ことば・おと(oto-man, Phonics Maze)」「ぶんをつくる(Puzzle Grammar, SVO Karuta, Quiz Maker)」「よむ・きく(Story Quiz, So-ta, Ymeyme)」「あそぶ(Word Detective)」のようにセクション分け。
   - カードに対象学年・所要時間・**進捗(⭐ 数やクリア率)** を表示。
   - 最上部に「きょうのおすすめ」1 枚 + 「つづきから」ボタン。
   - アイコンを統一(同じスタイルの SVG か絵文字に揃える。`MZ` を置き換え)。
5. **フィードバック演出の統一**: 正解=はなまる(`HanamaruMark` を全アプリで共通利用)+ チャイム、不正解=やさしいゆれ + ブザー。色だけでなくアイコン(○/?)でも示す。`prefers-reduced-motion` で演出を弱める。
6. **結果画面の共通コンポーネント** `ResultCard`: スコア・⭐ 評価・ベスト更新・「もういちど / つぎへ / ホーム」。`alert()` を置き換える。
7. **メタデータ整備**: サイト名(例: 「えいごのあそびば」など)を決め、各ページに `title` を設定、`lang="ja"`、`viewport`・`theme-color`・アイコン・PWA マニフェスト(ホーム画面に追加してアプリのように使える)。

## 3. ゲーム性向上計画

### 3-1. 全アプリ共通の「続けたくなる仕組み」
| 施策 | 内容 |
|------|------|
| ⭐ 3 段階評価 | 各ラウンド終了時に正答率・ヒント使用・時間で ⭐1〜3。ポータルに合計 ⭐ を表示 |
| スタンプ帳 / コレクション | クリアでスタンプやカードが手に入る。So-ta の「色がつく」体験をハブ全体に広げる |
| 日替わりチャレンジ | 日付シードで全員同じ 5 問(Story Quiz の seeded random を流用)。連続日数を記録 |
| 共通進捗ストア | `useSyncExternalStore` ベースの `app/lib/progress.ts` に一本化(Story Quiz 実装を一般化)。キーは `app:<id>` |
| 苦手の復習 | 間違えたカード/単語を記録し、次回の出題で優先(簡易な間隔反復) |
| アプリ間の導線 | Story Quiz → Puzzle Grammar(実装済み)を他にも広げる: oto-man で覚えた単語 → Word Detective のお題、SVO カルタのカード → Puzzle Grammar |

### 3-2. アプリ別
- **Puzzle Grammar**
  - ピースの形で役割が分かるので実質 2 択×3。レベルが上がるほど **形のヒントを消す**(全ピース同形)・ダミーを 2 枚に増やす。
  - 1 ラウンド 10 枚制にして ⭐ 評価(現在は 45 枚ぶっ通し)。
  - 完成時に文を読み上げながら **絵が動く/色がつく** ごほうび演出。
- **SVO Karuta**
  - H3・H4 を修正したうえで、VS AI に **キャラクター(ねこ先生など)と表情**、先取り時の「とった!」演出。
  - お手つき(誤タップ)に 1 秒のペナルティ(タイムトライアルでは +2 秒)で緊張感を出す。
  - ランキングをいつでも開けるボタン + 「自己ベストまで あと ○秒」表示。
- **Quiz Maker**
  - SVO の共通フック(`useGameTimer` / `useRanking` / `useVsMode` / `useSpeechRecognition`)へ移行して 1,300 行を半分以下に。
  - 選択肢数 UI の復活、デッキ(セット)ごとのクリア ⭐。
- **Word Detective**
  - 区別できないお題を解消(例: `train` に `long: true`、`desk` に `legs: true`・`computer` に `sound: true`、`cup` に `round: true`・`spoon` に `long: true`)。データ追加時に自動チェックするスクリプトを `scripts/` に置く。
  - **少ない質問で当てるほど高得点**(質問 3 回以内で ⭐3 など)。「のこりの候補」を絵で並べて、Yes/No のたびに消えていく「たんてい ボード」を表示すると推理の手応えが見える。
  - 役割交代モード(子どもがお題を決め、アプリが質問する)。
- **oto-man**
  - 形だけの認証を削除または保護者モード化。
  - レベルごとの単語コンプリート率を ⭐ で表示し、コンプリートでカードの絵柄が金色に。
- **Phonics Maze**
  - 迷路クリア数・連続クリアの記録がないので追加。「つぎ」で同じテンプレートを作り直すだけなので、クリアで次のテンプレートへ自動で進む。
  - 手数(遠回り)で ⭐ 評価、時間制限つきチャレンジ。
- **Story Quiz**
  - 未実装の typing / speech モードを段階的に実装(speech は SVO の音声認識を流用)。
  - 1 回目で正解した問題数で ⭐、⭐3 でおはなしの「おまけページ」解放。
- **So-ta The Alien**
  - 16 場面すべて色がついたら **完成した絵本を通しで読む** ごほうびモード(読み上げ + ページめくり)。
- **Ymeyme Rhyme**
  - 聞くだけから一歩進めて、韻をふむ語を選ぶミニクイズ、行の穴うめ、音読録音(自分の声を聞き比べる)。
